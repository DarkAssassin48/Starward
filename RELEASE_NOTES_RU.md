# Starward 0.18.0 fix mod

Основано на оригинальной версии **Starward 0.18.0 — Dreamland Fest**.

## Локализация времени

- Добавлены локализованные сокращения часов, минут и секунд для всех встроенных языков Starward.
- Русский формат использует `ч`, `м`, `с`; английский — `h`, `m`, `s`.
- Добавлен общий форматтер времени для сочетаний часов, минут и секунд.
- Исправлены жёстко заданные английские обозначения времени в статистике игрового времени, Театре Воображариума, Мрачном натиске, Обороне Шиюй и других связанных элементах интерфейса.
- Между числом и обозначением единицы времени добавлен пробел; отрицательные значения безопасно преобразуются в нулевое время.

## История молитв

- Исправлено наложение текста в строке средней статистики пятизвёздочных персонажей и предметов.
- Среднее значение, статистика UP и количество выпадений размещены в отдельных колонках.
- Добавлен перенос длинных локализованных строк вместо обрезания.

## Honkai: Star Rail — игровые записи

- Длинные названия этапов, режимов, боссов и противников теперь переносятся на дополнительные строки.
- Высота заголовков и карточек автоматически подстраивается под содержимое.
- Исправлены отсутствующие пробелы после закрывающей скобки и римских цифр.
- Изменения применены к Залу забвения, Чистому вымыслу, Иллюзии конца и Арбитражу аномалий.

### Чистый вымысел

- Под каждым отрядом добавлена кнопка выбранного усиления с официальной иконкой и локализованным названием.
- По нажатию открывается карточка с увеличенной иконкой, названием и полным описанием эффекта.
- Добавлен отдельный блок **«Механика Боевого духа»**.
- Поддерживаются поля API `simple_desc_mi18m`, `simple_desc_mi18n` и совместимое чтение через `JsonExtensionData`.
- Локализованное название механики сохраняется непосредственно внутри JSON-записи Чистого вымысла в SQLite для каждого отряда.
- При обновлении текущего и предыдущего периода название сохраняется на выбранном языке Starward.
- Старые записи получают название механики после повторного обновления.
- Исправлены отступы между датой, персонажами, усилением и соседними отрядами; для всех трёх отрядов используется единый интервал 8 px.
- Фиксированная высота карточек заменена минимальной, чтобы интерфейс корректно расширялся.

### Иллюзия конца

- Под составом каждого отряда добавлена кнопка выбранного усиления с иконкой, названием и полным описанием.
- Поддержано чтение `desc_mi18n` из ответа HoYoLAB.
- Усиления отображаются для первого, второго и третьего отряда.
- Исправлены переносы названий сложности, боссов и описаний отрядов.
- Исправлен фон третьего отряда в верхнем информационном блоке.
- Карточки получили динамическую минимальную высоту и выровненные внутренние отступы.

### Зал забвения

- Длинные названия этапов переносятся максимум на две строки вместо обрезания многоточием.
- Высота заголовка автоматически подстраивается под локализованный текст.
- Исправлены слитные названия с римскими цифрами и закрывающими скобками.

### Арбитраж аномалий

- Длинные названия боссов и противников переносятся на две строки.
- Зарезервировано место, чтобы текст не заходил под изображение противника.
- Исправлены отсутствующие пробелы в составных названиях.

## Genshin Impact

### История расходов в аккаунте

- Добавлена поддержка нового официального URL HoYoLAB:
  `https://gs.hoyoverse.com/event/user-game-search/genshin/index.html`
- Сохранена поддержка старого адреса `cs.hoyoverse.com/event/user-game-search/hk4e/index.html`.
- URL разбирается через безопасную проверку `Uri`, разрешены только HTTPS-ссылки.
- Проверяется соответствие параметра `game_biz` выбранному региону.
- Фрагмент `#/moneyRecord` больше не мешает импорту.
- Исправлена ошибка `ArgumentException: Input URL is invalid` для нового формата ссылки.

## Автообновление HoYoLAB Toolbox

- Перенесена полноценная функция автообновления игровых записей из предыдущей версии форка.
- Планировщик работает в фоне, пока Starward запущен, и выполняет пропущенные обновления при следующем запуске.
- Для каждой игры отдельно доступны интервалы: отключено, при запуске, ежедневно, еженедельно и ежемесячно.
- Добавлена отдельная страница настроек **HoYoLAB Toolbox Auto Refresh**.
- Доступны ручное обновление одной игры и обновление всех игр сразу.
- Отображаются время последнего успешного и следующего запланированного обновления.
- После неудачной автоматической попытки действует двухчасовая задержка перед повтором.
- Успешное обновление отправляет уведомление открытым страницам игровых записей.

## Другие исправления интерфейса

- В Мрачном натиске секунды используют сокращение текущего языка; длинные названия противников переносятся на новую строку.
- В Театре Воображариума удалены жёстко заданные английские `m` и `s`.
- В Обороне Шиюй время прохождения использует локализованные минуты и секунды с сохранением двузначного формата секунд.

## Технические изменения

- Добавлен переиспользуемый контрол `StarRailBuffButton`.
- Добавлен общий помощник нормализации названий этапов Star Rail.
- Название Механики Боевого духа хранится внутри существующего JSON записи — миграция схемы базы данных не требуется.
- Сохранена совместимость со старыми записями и старыми форматами входных URL.
- Проверены сборки Release/Debug для x64 и ARM64.
